# Infrastructure: PostgreSQL user store

`internal/infrastructure/postgres/`. One concrete type, `UserStore`, keeps users in PostgreSQL through the code sqlc generates, and satisfies the repository port of each user use case at once:

| Method | `createUserRepository` (`create_user.go`) | `updateUserRepository` (`update_user.go`) |
|---|---|---|
| `CreateUser` | ✓ | |
| `ExistsUserByEmail` | ✓ | ✓ |
| `GetUser` | | ✓ |
| `UpdateUser` | | ✓ |

- [db.go](#dbgo): `Open`, with its connection settings
- [errors.go](#errorsgo): the unique violation, recognized
- [user_store.go](#user_storego): the four methods of the ports
- [user_store_test.go](#user_store_testgo): the store against a real database
- [What stays out of this package](#what-stays-out-of-this-package)

It holds a `*pgxpool.Pool` from `pgx/v5`. The tables, the migrations, the queries, and `sqlc.yaml` follow `go-sql` (its `references/queries-postgres.md`), with one more query for the email check:

```sql
-- name: ExistsUserAccountByEmail :one
-- uq_user_account_email is the index
SELECT EXISTS (
    SELECT 1 FROM user_account WHERE email = @email
);
```

```
internal/infrastructure/postgres/
├── migrations/          # goose, the schema sqlc reads
├── queries/             # user_account.sql
├── sqlcgen/             # generated by sqlc: never edited
├── db.go                # Open: the connection, configured once
├── errors.go            # driver error translation
├── user_store.go
└── user_store_test.go   # against a real database, migrated with the real migrations
```

What differs from the other examples:

- **`CreateUserAccountParams` is cast from the entity**: sqlc generates it with the same fields, in the same order, with the same types.
- **`UpdateUserAccountParams` is mapped, field by field.** The `UPDATE` sets every column but `id` and `created_at`, and its parameters end with the `id` of the `WHERE`, so it has neither the entity's fields nor their order.
- **An update that matches no row** returns `ErrUserNotFound`, from the row count of `:execrows`, without reading the row first.
- **`scanTimesInUTC`** makes pgx return `timestamptz` values in `time.UTC`, so a user read back is equal to the one written, field by field.
- **A unique violation is recognized by its constraint name** (`uq_user_account_email`), from the SQLSTATE `23505` of the `*pgconn.PgError`.
- **The test needs Docker.** It starts a PostgreSQL container with testcontainers-go, once for the whole test, since starting one takes a few seconds.

## db.go

`internal/infrastructure/postgres/db.go`

```go
package postgres

import (
	"context"
	"fmt"
	"time"

	"github.com/jackc/pgx/v5"
	"github.com/jackc/pgx/v5/pgtype"
	"github.com/jackc/pgx/v5/pgxpool"
)

// Open connects a pool to databaseURL. The URL comes from the config, passed by main.
func Open(ctx context.Context, databaseURL string) (*pgxpool.Pool, error) {
	cfg, err := pgxpool.ParseConfig(databaseURL)
	if err != nil {
		return nil, fmt.Errorf("parsing database url: %w", err)
	}
	cfg.AfterConnect = scanTimesInUTC

	pool, err := pgxpool.NewWithConfig(ctx, cfg)
	if err != nil {
		return nil, fmt.Errorf("creating database pool: %w", err)
	}

	// the pool connects lazily: ping, so a wrong URL fails at start, not at the first request
	if err := pool.Ping(ctx); err != nil {
		pool.Close()
		return nil, fmt.Errorf("connecting to the database: %w", err)
	}

	return pool, nil
}

// scanTimesInUTC makes pgx return timestamptz values in UTC instead of the
// machine's local time zone: the domain expects UTC.
func scanTimesInUTC(_ context.Context, conn *pgx.Conn) error {
	conn.TypeMap().RegisterType(&pgtype.Type{
		Name:  "timestamptz",
		OID:   pgtype.TimestamptzOID,
		Codec: &pgtype.TimestamptzCodec{ScanLocation: time.UTC},
	})
	return nil
}
```

## errors.go

`internal/infrastructure/postgres/errors.go`

```go
package postgres

import (
	"errors"

	"github.com/jackc/pgx/v5/pgconn"
)

// uniqueViolation is the SQLSTATE of a unique constraint violation.
const uniqueViolation = "23505"

// isUniqueViolation reports whether err violates the named unique constraint
// (uq_user_account_email): sql-schema names every constraint for this.
func isUniqueViolation(err error, constraint string) bool {
	var e *pgconn.PgError
	return errors.As(err, &e) && e.Code == uniqueViolation && e.ConstraintName == constraint
}
```

## user_store.go

`internal/infrastructure/postgres/user_store.go`

```go
package postgres

import (
	"context"
	"errors"
	"fmt"
	"uuid"

	"github.com/jackc/pgx/v5"
	"github.com/jackc/pgx/v5/pgxpool"

	usecaseuser "internal/application/usecases/user"
	"internal/domain/user"
	"internal/infrastructure/postgres/sqlcgen"
)

type UserStore struct {
	queries *sqlcgen.Queries
}

// The pool comes from the constructor: main opens it with Open and closes it.
func NewUserStore(pool *pgxpool.Pool) *UserStore {
	return &UserStore{queries: sqlcgen.New(pool)}
}

func (s *UserStore) CreateUser(ctx context.Context, u user.User) error {
	// same fields, same order, same types as the entity: a cast
	err := s.queries.CreateUserAccount(ctx, sqlcgen.CreateUserAccountParams(u))
	if isUniqueViolation(err, "uq_user_account_email") {
		return usecaseuser.ErrEmailAlreadyExists
	}
	if err != nil {
		return fmt.Errorf("inserting user %s: %w", u.ID, err)
	}

	return nil
}

func (s *UserStore) GetUser(ctx context.Context, id uuid.UUID) (user.User, error) {
	m, err := s.queries.GetUserAccount(ctx, id)
	if errors.Is(err, pgx.ErrNoRows) {
		return user.User{}, usecaseuser.ErrUserNotFound
	}
	if err != nil {
		return user.User{}, fmt.Errorf("selecting user %s: %w", id, err)
	}

	// stored data is trusted: the cast does not call ParseEmail again
	return user.User(m), nil
}

func (s *UserStore) ExistsUserByEmail(ctx context.Context, email user.Email) (bool, error) {
	exists, err := s.queries.ExistsUserAccountByEmail(ctx, email)
	if err != nil {
		return false, fmt.Errorf("checking user email: %w", err)
	}

	return exists, nil
}

func (s *UserStore) UpdateUser(ctx context.Context, u user.User) error {
	// Not a cast: the UPDATE sets every column but id and created_at, and its
	// parameters end with the id of the WHERE, so the shapes differ.
	rows, err := s.queries.UpdateUserAccount(ctx, sqlcgen.UpdateUserAccountParams{
		Email:           u.Email,
		EmailVerifiedAt: u.EmailVerifiedAt,
		PasswordHash:    u.PasswordHash,
		AvatarKey:       u.AvatarKey,
		UpdatedAt:       u.UpdatedAt,
		ID:              u.ID,
	})
	if isUniqueViolation(err, "uq_user_account_email") {
		return usecaseuser.ErrEmailAlreadyExists
	}
	if err != nil {
		return fmt.Errorf("updating user %s: %w", u.ID, err)
	}

	// :execrows: no row means no user with this id, without reading it first
	if rows == 0 {
		return usecaseuser.ErrUserNotFound
	}

	return nil
}
```

## user_store_test.go

`internal/infrastructure/postgres/user_store_test.go`

```go
package postgres

import (
	"context"
	"errors"
	"os"
	"testing"
	"time"
	"uuid"

	"github.com/jackc/pgx/v5/stdlib"
	"github.com/pressly/goose/v3"
	"github.com/testcontainers/testcontainers-go"
	tcpostgres "github.com/testcontainers/testcontainers-go/modules/postgres"

	usecaseuser "internal/application/usecases/user"
	"internal/domain/user"
)

// newTestStore starts a PostgreSQL container, applies the real migrations as
// make migrate-up does, and returns a store on it. It needs Docker.
func newTestStore(t *testing.T) *UserStore {
	t.Helper()
	ctx := context.Background()

	container, err := tcpostgres.Run(ctx, "postgres:17-alpine",
		tcpostgres.WithDatabase("app"),
		tcpostgres.BasicWaitStrategies(),
	)
	testcontainers.CleanupContainer(t, container)
	if err != nil {
		t.Fatalf("starting postgres: %v", err)
	}

	url, err := container.ConnectionString(ctx, "sslmode=disable")
	if err != nil {
		t.Fatal(err)
	}

	pool, err := Open(ctx, url)
	if err != nil {
		t.Fatal(err)
	}
	t.Cleanup(pool.Close)

	// goose runs on database/sql: the same pool, through pgx's stdlib adapter
	db := stdlib.OpenDBFromPool(pool)
	t.Cleanup(func() { db.Close() })
	provider, err := goose.NewProvider(goose.DialectPostgres, db, os.DirFS("migrations"))
	if err != nil {
		t.Fatal(err)
	}
	if _, err := provider.Up(ctx); err != nil {
		t.Fatalf("migrating: %v", err)
	}

	return NewUserStore(pool)
}

func newUser(email string) user.User {
	// PostgreSQL keeps microseconds: truncate, so the value read back is equal
	now := time.Now().UTC().Truncate(time.Microsecond)
	return user.User{ID: uuid.NewV7(), Email: user.Email(email), PasswordHash: "hash", CreatedAt: now, UpdatedAt: now}
}

// One container for the whole test: starting one takes a few seconds.
func TestUserStore(t *testing.T) {
	ctx := context.Background()
	store := newTestStore(t)

	t.Run("create and get", func(t *testing.T) {
		u := newUser("ada@example.com")
		if err := store.CreateUser(ctx, u); err != nil {
			t.Fatalf("CreateUser: %v", err)
		}

		got, err := store.GetUser(ctx, u.ID)
		if err != nil {
			t.Fatalf("GetUser: %v", err)
		}
		// scanTimesInUTC: the value comes back in time.UTC, so the whole entity is equal
		if got != u {
			t.Errorf("GetUser = %+v, want %+v", got, u)
		}
	})

	t.Run("duplicate email", func(t *testing.T) {
		err := store.CreateUser(ctx, newUser("ada@example.com"))
		if !errors.Is(err, usecaseuser.ErrEmailAlreadyExists) {
			t.Errorf("CreateUser = %v, want ErrEmailAlreadyExists", err)
		}

		exists, err := store.ExistsUserByEmail(ctx, "ada@example.com")
		if err != nil || !exists {
			t.Errorf("ExistsUserByEmail = %v, %v, want true", exists, err)
		}
	})

	t.Run("missing user", func(t *testing.T) {
		if _, err := store.GetUser(ctx, uuid.NewV7()); !errors.Is(err, usecaseuser.ErrUserNotFound) {
			t.Errorf("GetUser = %v, want ErrUserNotFound", err)
		}
		if err := store.UpdateUser(ctx, newUser("nobody@example.com")); !errors.Is(err, usecaseuser.ErrUserNotFound) {
			t.Errorf("UpdateUser = %v, want ErrUserNotFound", err)
		}
	})

	t.Run("update", func(t *testing.T) {
		u := newUser("grace@example.com")
		if err := store.CreateUser(ctx, u); err != nil {
			t.Fatal(err)
		}

		key := "avatar.png"
		u.Email, u.AvatarKey, u.UpdatedAt = "grace.hopper@example.com", &key, u.UpdatedAt.Add(time.Minute)
		if err := store.UpdateUser(ctx, u); err != nil {
			t.Fatalf("UpdateUser: %v", err)
		}

		got, err := store.GetUser(ctx, u.ID)
		if err != nil {
			t.Fatal(err)
		}
		if got.Email != u.Email || got.AvatarKey == nil || *got.AvatarKey != key || !got.UpdatedAt.Equal(u.UpdatedAt) {
			t.Errorf("after UpdateUser = %+v, want %+v", got, u)
		}
	})
}
```

## What stays out of this package

- **Deciding what a duplicate email means**: `CreateUserUC` checks `ExistsUserByEmail` first. The store still translates a unique violation, for two requests that race past that check.
- **The connection settings**: the database URL or path comes from the config, which `main` loads and passes to `Open`. `main` also closes the connection.
- **Running the migrations**: `make migrate-up`, before the application starts (`migrations.md` in `go-sql`). The test runs them through goose only to build its database.
